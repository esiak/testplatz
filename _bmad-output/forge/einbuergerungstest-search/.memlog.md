idea: Website aggregating Einbürgerungstest appointments from many VHS sites, searchable by distance from a location
goal: Test whether the idea holds up
status: complete
updated: 2026-10-25T19:28

- (decision) Search-only: users find appointments here, booking happens on the VHS site. No booking, no accounts at VHS.
- (assumption) Central claim to test first: VHS appointment data can be read by machine reliably and legally.
- (crack) VHS sites don't share one format: Berlin uses service.berlin.de booking with slots posted at irregular times; Pankow takes registration by emailed form from a fixed opening time; Rhein-Sieg and Saarbrücken publish PDFs or programmes with dates only. Many show a test date and when registration opens, but not whether seats are free.
- (decision) Must show: (1) the test date exists and (2) when registration opens. (3) Free seats right now: show it where the site publishes it.
- (note) User says Bavarian VHS sites show this info online (not yet verified).
- (crack) Not only VHS: BAMF lists 116 test centres in Bavaria, about 101 VHS and 15 others (Kolping, bfz, DAA, ...). The product must cover all test centres or users still have to check sites by hand.
- (direction) The BAMF test-centre list gives names and addresses for every centre, which can feed the distance search.
- (direction) Data access mostly holds up for Bavaria: of 78 VHS sites checked, 30 run KuferWeb (webbasys) and about 25 run the ITEM KG TYPO3 setup (/p/...-NNN-CAT URLs, incl. MVHS, Würzburg, Fürth, Bad Kissingen). Two readers could cover about 70% of sites; about 23 are unknown or blocked automated fetches.
- (crack) None of the 3 sample sites shows a registration opening time; they show a test date, a deadline (3–5 weeks before) and a booked-out flag (Aichach: all 12.11 sessions AUSGEBUCHT). Need #2 may not exist as data in Bavaria.
- (crack) Bad Kissingen: registration in person only, cash. Some listings will be impossible to book remotely, and the product must say so.
- (note) Aichach-Friedberg requires residence in Bavaria. Tests are probably limited to your own state, so cover one state at a time.
- (decision) v1 = search page by distance. v2 = alerts for new dates or free seats near me.
- (direction) v1 should keep history from day one (first-seen time per test date), so it can show a 'new since' badge and v2 alerts are cheap to add.
- (lock) v1 coverage = read the Kufer and ITEM KG sites automatically; show every other BAMF test centre on the map as 'not checked automatically, see website' with a link. Never let a gap look like 'nothing available'.
- (note) No existing aggregator or distance search for test dates found (two searches; weak evidence, not proof). Guides still tell people to google 'VHS Einbürgerungstest + city'.
- (note) Scraped pages include instructor names (e.g. 'Wer: Monika Steiner'). Store only date, time, place, status, and link; no personal data.
- (lock) Free public tool, maintained as a side project. No monetisation. Running costs near zero.
- (decision) Show staleness: each listing and each reader shows 'last checked', so breakage is visible and never silent.
- (lock) v1 = Bavaria only: all ~116 BAMF test centres in Bavaria, none outside. Other states later, one at a time.
- (lock) Distance = straight-line km; link out to map directions.
- (lock) Check each site 2-4x/day with an identified bot, robots.txt respected; remove any centre that asks.
