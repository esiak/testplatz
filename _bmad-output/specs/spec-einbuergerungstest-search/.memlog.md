- (capability) CAP-8: a provider can be removed from collection on request.
- (constraint) Bavaria only in v1 (tests require residence in Bavaria).
- (constraint) Search only; no booking, no accounts at providers.
- (constraint) Free public side project: near-zero running cost, no monetisation; rules out paid APIs and heavy infra.
- (constraint) Polite collection: identified bot, robots.txt respected, max 4 checks/site/day.
- (constraint) No personal data from provider pages stored (e.g. instructor names); only date, time, place, status, deadline, method, link.
- (constraint) Gaps must never read as 'nothing available'.

- (decision) Coverage denominator (user choice): centres with a known test_page_url that are not opted out, not robots-blocked, and whose test page answered 2xx. The script first looks for missing test page URLs, which grows the denominator.
- (decision) Improved parsers ship into the daily pipeline as readers (user choice); the script iterates on the real readers, not a separate parser.

- (capability) CAP-12: operator can run a one-off local coverage script that politely fetches every centre's test page (finding missing test page URLs first), caches the pages locally, and reports each centre's parse outcome; parsing re-runs against the cache without new requests.
- (capability) CAP-13: at least 90% of centres in the coverage denominator are parsed successfully by readers in the daily pipeline.
- (capability) CAP-14: every daily run reports parse statistics to the operator: counts per outcome and reason, per reader, and the coverage percentage.
- (decision) Success = reader returns ok with listings valid against RawListing, or ok with zero listings only when the reader's structure check proves the page lists none (AD-4). Any other result is a parse failure.
- (constraint) Script uses pipeline/fetch only (UA, robots, delay, timeout); its requests count against the 4 visits per host per rolling 24 h, are recorded in data/state/visits.json and committed, and never push a host over budget.
- (constraint) Raw page cache stays local and gitignored; only trimmed pages chosen as reader fixtures are committed. Page bodies never reach published data.
- (constraint) Readers stay pure and cheerio-only (AD-3/AD-4); no headless browser. A site that needs JavaScript to show dates counts as a failure.
- (constraint) Discovered test page URLs and new reader assignments are proposed to the operator and applied to centres.json only after review (AD-8: directory is human-owned).
