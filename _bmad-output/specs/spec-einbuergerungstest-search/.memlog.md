- (capability) CAP-1: user enters a location and radius, gets test dates across all Bavarian test centres sorted by straight-line distance.
- (capability) CAP-2: each test date shows date/time, place, status (free/booked out/unknown), registration deadline, registration method, link to provider page.
- (capability) CAP-3: system collects test dates automatically from KuferWeb and ITEM KG sites, 2-4x/day.
- (capability) CAP-4: centres without an automatic reader appear in results as 'not checked automatically, see website' with link; never omitted.
- (capability) CAP-5: every listing and every reader shows 'last checked'; a reader that fails is visibly flagged, not silent.
- (capability) CAP-6: test dates first seen in the last 24h carry a 'new' badge (first-seen time stored per date).
- (capability) CAP-7: centre directory = all BAMF-listed Bavarian test centres (VHS and non-VHS), each with address and coordinates.
- (capability) CAP-8: a provider can be removed from collection on request.
- (constraint) Bavaria only in v1 (tests require residence in Bavaria).
- (constraint) Search only; no booking, no accounts at providers.
- (constraint) Free public side project: near-zero running cost, no monetisation; rules out paid APIs and heavy infra.
- (constraint) Polite collection: identified bot, robots.txt respected, max 4 checks/site/day.
- (constraint) No personal data from provider pages stored (e.g. instructor names); only date, time, place, status, deadline, method, link.
- (constraint) Gaps must never read as 'nothing available'.
- (decision) Non-goals: booking; alerts (v2); other states; travel-time routing; monetisation; showing 'registration opens at'.
- (decision) Companion data-sources.md holds reader catalogue, listing fields, status mapping.
- (assumption) Vendor share (~30 Kufer, ~25 ITEM KG of 78 VHS) from homepage fingerprints only; per-site test pages unverified.
- (assumption) BAMF test-centre list (via rtpartner.de republication) is the centre directory source; refresh path unconfirmed.
- (question) Legal pages: a public German website needs an Impressum and a privacy policy; who is the named operator?
- (question) UI language: German only, or German + English (many users are non-native)?
- (question) Geocoding: which free geocoder for centre addresses and user-entered locations?
- (question) Where does the BAMF centre list come from officially, and how is it refreshed?
