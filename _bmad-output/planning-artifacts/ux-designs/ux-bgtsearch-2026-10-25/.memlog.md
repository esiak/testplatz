- (decision) Core feeling: all required information in one place; when something is stale, that is easy to understand.
- (decision) Every listing links to the exact provider page for that test date (deep link), not the provider homepage or its search.
- (decision) Inspiration: ImmoScout24 (search results layout), far less information.
- (decision) Anti-patterns: dead links; filters that silently drop results because data is missing.
- (decision) From ImmoScout24: the key-facts row on each result card (like price / rooms / m² under the photo); a few facts, scannable at a glance.
- (decision) From ImmoScout24: one search bar with location plus radius (Umkreis).
- (decision) Not taken from ImmoScout24 (not named): map view, filter panel, photos.
